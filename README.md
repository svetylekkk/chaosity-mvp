# Chaosity · Telegram Mini App (MVP)

Интерактивный прототип: пользователь описывает маникюр своими словами →
система выделяет теги → пользователь правит теги → лента работ в стиле Pinterest →
страница работы с похожими работами → профиль мастера.

Один статический файл `index.html`, без сборки и зависимостей.

## Как устроено
- Теги выделяются по словарю ключевых слов (`TAGS` в `index.html`).
- Совпадение = сумма весов совпавших тегов / сумма весов тегов запроса.
  Веса: стиль 4, длина / форма / дизайн 2, цвет / подход / техника 1. За похожую характеристику начисляется половина.
- Похожие работы считаются по тегам открытой работы, сама работа исключается.
- Лайки и сохранения хранятся в `localStorage` браузера.
- Внутри Telegram скрывается нарисованная шапка и включается системная кнопка «Назад».

## Как заменить заглушки на настоящие фото
1. Положи фото в папку `images/` (например `images/m1.jpg`).
2. В массиве `WORKS` у нужной работы добавь поле `img:'images/m1.jpg'`.
3. Закоммить и запушь — GitHub Pages обновит сайт сам.
